# Native final-output boundary pilot

This pilot follows `../FIRST_RELEASE_CONTRACT_20260910.md`. Release targets are
model/effort **cohort medians**, not thresholds for this one maintenance area.
The seven-cell inventory is fixed there; this pilot cannot freeze a model alone.

One fresh randomized pair for Astra Extra High, then one for Sol High, on the
existing maintenance task. No High control reused for Extra High. The task is
known development material. Both arms receive the same source files, public tests
and normal prose/code final-report requirement; no private solution is supplied.
Candidate gets complete file contents, the frozen delegation base/skill, and one
caller-attached `helix_apply_edits` internal tool. Control has ordinary tools/default
base. Candidate retains ordinary tools, semantic review and independent probes.

The internal tool accepts source version and exact old/new edits, stages/checks
the model's code and publishes only on actual PASS. It returns receipts to the
model. The model then writes the ordinary final answer. There is no caller-written
final, selector final, forced one-segment budget, native-turn elimination claim or
hidden final serialization. All follow-up model segments and tool schemas count.

Exact caller authority covers the frozen task, protected files, configuration,
checker and executor code; source versions bind each edit. A predeclared tracked
empty publication lock is identical in both task roots. Raw evidence and failures
remain durable. Duplicate delivery returns the same result; an uncertain claim is
not re-executed. Recovery can close an already-published exact result from retained
prepared/check evidence; absent/changed publication or authority requires attention.
This is cooperative local integrity, not a hostile-host security guarantee.

Before inference: test actual publication, failed checks, stale state, changed
authority, duplicates, restart and lost publication acknowledgement; verify native
Extra High + dynamic-tool registration with zero turn/start requests. Freeze concrete
scripts, prompts, all four roots and effective configuration before either pair.
Native code/default settings are not altered globally. Each actual thread and turn
must explicitly carry/return the requested model and effort.

At most two native user turns per arm, the second only after actual artifact-check
failure. Internal model/tool segments are unrestricted and fully charged. No blind
retries, prompt tuning or changed grader after outcomes. Infrastructure/integrity
failure stops globally; any exact recovery is separately classified with the
original failure retained. No broken response is reported as a completed task.

Audit full native usage/identity/config receipts, exact artifacts, internal request/
response provenance, protected files and model-written final items after tool
completion. Public/regression and94 independent cases remain unchanged. Explicitly
review the answer for completeness and truthful assertions; wrapper PASS is not
capability parity. Recheck any novel semantic probes the control generates against
the candidate. This finite pilot qualifies the interface only; the complete cohort
and hostile capability/workflow gates are still required before model freeze.

Report separate input/output/uncached savings, reported reasoning, calls/segments,
setup, I/O, storage, recovery, latency boundaries and all attempts. Price snapshots
are dated; HUD rates refresh/expire. Do not infer Codex quota from API tariffs or
hide coordinator research cost. Evaluate remaining cohort feasibility from observed
costs; never substitute a per-area success for the user's median release condition.
