  default is intended. Do not choose one unilaterally. Grade the normal answer's
  meaning manually against this rubric; a keyword match alone is insufficient.
- E25: all128 valid graph-oracle variants,10 invalid variants, exact large integers,
  explicit adjacency flag, canonical result and input non-mutation. Review changes
  for the requested API and truthful final claims.
- E38: prior checks plus exact Unicode/trailing whitespace/leading zeros, duplicate
  tags and input order, empty strings, invalid rows, and the exact plan.json derived
  from the early note selected only at E38. A model must not infer normalized values.
- E50: prior checks plus invalid-late-row rollback for present/absent destinations,
  valid publication, and a separate-process replace-failure injection. Source review
  must establish atomic replacement on the local filesystem; finite tests alone
  do not prove all concurrency/durability behavior.
