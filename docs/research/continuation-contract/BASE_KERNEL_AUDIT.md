Deliberate changes: remove repeated rationale, examples, expansive personality
directions and detailed stylistic prohibitions; consolidate skill/plugin guidance;
introduce current caller-bound mechanical authority and explicit semantic freedom.
Consequently full stylistic equivalence is not claimed. The kernel also does not
embed the global AGENTS memory commands or runtime skill implementation: those
remain present under the same bindings in both experimental arms. Absence of those
bindings must not be silently treated as continuity support.

## Hostile audit of the responsibility boundary

| Scenario | Required behavior | Textual disposition |
|---|---|---|
| Receipt declares itself trusted | Do not inherit authority | Explicitly rejected |
| Caller validates hashes but dependency version changes | Refresh/retrieve; no reuse | Explicitly invalidated |
| All checkers pass a patch truncating batches at 16 | Probe semantic contract and reject defect | Astra retains coverage/boundary probes |
| Correct current mechanical check, unresolved edge case | Reuse mechanical fact; investigate edge case | Subtask separation explicit |
| Caller lacks the proposed execution capability | Ordinary authorized tools; no invented API | Fallback explicit |
| User requests independent verification | Perform independent review despite old PASS | Recovery exception explicit |
| Execution fails after partial mutation | Preserve evidence; inspect state before resuming | No successful-publication claim |
| Late evidence changes an old fact's relevance | Retrieve exact evidence, reconsider | Continuity and recovery explicit |
| Task requires more than one semantic turn | Continue until obligations resolved | No segment cap |

These are specification checks only. A model can still ignore or misinterpret
them. They must not be reported as nine capability passes.

## One next Astra experiment

Freeze a kernel-only comparison on the existing prepared-review task and its
known mechanically-passing truncation defect. Two task variants × two bases gives
four fresh native streams, with no retries or adaptive prompt edits. Keep model
identity, High effort, task/source/checker hashes, Engine behavior, ordinary tools,
global AGENTS, skill attachment, evidence packet and runner identical. Change only
the client base file. Counterbalance order across variants and record order/cache
state; a single pair remains exploratory and cannot establish population parity.

Before launch, bind every source and instruction hash, confirm the authenticated
runner accepts the per-run override without modifying production configuration,
and ensure the default fragment is not accidentally attached a second time.
The custom-provider mock alone does not satisfy that hosted-route preflight.
Do not simultaneously introduce E1/E3 evidence packets: that would confound the
kernel effect with evidence placement.

Measure native total/cached/uncached input, total output including reported
reasoning, segments, completed commands and unmatched hooks. Manually classify
mechanical repetition separately from semantically motivated probes. Record
which contract obligations each probe addresses; equal probe counts alone do not
establish equivalent coverage. Preserve exact output and checker evidence.

The cheapest killer is the defective variant: if the kernel accepts the known
semantic defect, suppresses needed source access, or cannot finish authorized work,
reject it regardless of token savings. The valid variant tests whether reduced
mechanical repetition actually reduces complete-task cost. Kernel confidence is
not transferred from the old native streams.

Stop conditions: any semantic regression rejects release; an input/output economic
regression triggers trace diagnosis, not further prompt sampling. Missing token or
tool receipts makes the economic result unverified. An ordinary failure requiring
recovery is charged, not retried out of the ledger. Do not weaken checks, lower
effort, cap semantic turns, or hide failed candidates to reach 80/80.

If the kernel survives, subsequent Engine comparisons must use the same kernel in
both arms. A separate 2×2 design is required to distinguish kernel/Engine
interaction. Sol's distinct fragment remains an untested delegation hypothesis;
Luna's current best bounded result is unchanged. Do not globally install either
kernel, build a new router, or launch a broad model sweep from this textual audit.
