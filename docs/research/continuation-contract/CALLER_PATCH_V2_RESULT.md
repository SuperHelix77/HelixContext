diff, artifact identity, and actual checker receipt. Astra still returns its own
semantic assessment and unresolved obligations; no length limit was imposed. The

## Residual diagnosis

V1's candidate used 387 output tokens; V2 used 507 (**+120**). Reported reasoning
rose 124→215 (**+91**); remaining reported output rose 263→292 (**+29**). The
source stayed 86 o200k proxy tokens, while assessment grew 135→163. Proxy text
counts are not a native partition or a causal explanation. The V2 native control
also used fewer output tokens (955 versus V1's 1,135). Do not merge denominators.

The explicit reporting responsibility did not produce a shorter semantic
assessment in this observation. It did not reduce output cost. Random variation,
order and prompt effects are not isolated by these two separate development pairs;
this does not prove every possible caller report strategy harmful.

At V2's actual control, 80% output saving permits **191 tokens**. The candidate's
215 reported reasoning tokens already exceed that number. Holding that reported
reasoning fixed, deleting every visible output byte still cannot meet 80% output.
This conditional arithmetic is not a lower bound on Astra cognition. Do not lower
reasoning or suppress semantic challenges to manufacture a pass.

## Disposition

Caller-owned exact patch realization has now crossed 80% input savings in two
fresh pairs on the same development fixture, with output savings of 65.90% and
46.91%. This is repeated fixture evidence, not independent task replication or a
universal policy. The reporting addition is not economically qualified and does
not replace V1. Neither policy meets 80/80 or is promoted to production admission.

Stop report-wording optimization on this fixture. A useful next test must probe
transfer/failure recovery of the proven mechanical boundary or amortized reuse of
already-established semantics, with initial preparation charged and a fresh
matched denominator. It must preserve novel semantic judgment rather than
repeatedly asking Astra to explain less. The representative Luna/Sol/Astra and
latent-future-relevance model gates remain open.
