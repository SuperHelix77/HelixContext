# Astra / Sol transition transfer V1 — frozen before inference

Two fresh pairs, Astra High and Sol High, on the existing W50 development fixture.
This transfers Luna's minimal policy/amendment selector plus the durable passive
workflow. It does not replace the three failed coding qualification suites.

Both arms use the current default client base, High effort, ordinary tools, an
isolated tracked Git root, actual scoped memory preflight, and caller persistence.
Native control processes all 49 explicit record-and-ACK requests and the final
semantic request in one persistent thread. Candidate Engine records/delivers the
49 ACKs and calls the same model for policy/amendment selection at the final
request. Engine derives only the mechanically entailed fields/reason under the
existing bounded rule schema. The model retains authority selection, semantic
review, exact older-evidence access and escalation on insufficient evidence.

Both arms use the same durable ledger after their respective ACK producer. The
candidate stores raw events without predicting future relevance. At the final
request, all exact subject-matching records are supplied; complete raw history is
recoverable on disk. No preselected policy or proposed answer is supplied.
The known fixture's request and gold remain unchanged. This is not a fresh task
holdout, independent researcher replication or general intelligence proof.

Four isolated roots are registered before one config freeze, with zero model
turns during registration. Only already overridden GUI model/effort defaults may
change thereafter. Default-base hashes, actual native model/effort, source files,
raw/native receipts, all ACKs, recovered event bytes, final checks and unchanged
caller archive are audited. Randomized arm order is frozen per model; no control
reuse, prompt adjustment or blind retry. Runtime/binding failure stops the run.
Final semantic failures are retained rather than repaired from gold answers.

There are at most 102 submitted native turns: 50 control + 1 candidate per model.
This bounds the experiment, not model tool segments or a product's semantic
review. All actual segments and failed attempts are charged. A semantic escalation
is incomplete task evidence, not a zero-cost success. No model effort/tool removal.

Report total input, output, cached/uncached input, reported reasoning, segments,
native/raw hashes, memory preparation, ledger I/O, setup and elapsed costs.
Record coordinator research costs separately. Cache is observed, not controlled;
no monetary/uncached claim follows from a total-input percentage.

Per model, ≥80/80 with exact checks permits a bounded development freeze; ≥75/75
permits only a 75/75 candidate. Otherwise diagnose the residual without changing
this run. Any result remains N=1 on this family, separate from coding/retrieval,
hostile changed-authority cases and normal Codex-app integration.
