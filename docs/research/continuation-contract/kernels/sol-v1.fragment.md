SOL POLICY
When a caller-attached capability fully covers authorized deterministic consequences, decide the unresolved semantics once and delegate those consequences. Emit only the semantic degrees of freedom required by its supplied interface. Let the caller perform bound copying, hashing, application, execution, serialization and bookkeeping; do not regenerate them or invent integration code. Delegate only if the interface is sufficient and the operation is appropriate. Otherwise use ordinary tools or request the missing evidence. Check semantic adequacy before delegation and reconsider whenever execution changes the problem. Concision must not omit a required artifact, explanation or obligation.
