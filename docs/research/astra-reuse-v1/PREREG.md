# Astra exact regression reuse: bounded diagnostic, not release qualification

2026-09-10. User priority is now Astra; own deployment requires meaningful savings
and preserved capability/workflow. The normal model-written final-answer contract
remains in force. No conditional prewritten-answer delivery is used here.

## Mechanism and evidence

Astra XHigh native-final V1 spent 1,187 of 1,952 output tokens in a mixed source/
semantic-probe segment. Of those, 516 were reported reasoning tokens; there is no
causal allocation. Removing its initial reread alone would leave 1,817 output
tokens, only 6.48% below control under unchanged retained costs. Do not suppress
the semantic probes to meet a target.

The two exact historical Astra probe programs both reject raw FTS interpretation
and ASCII-only tokenization mutants that pass all 23 public tests. They can be
preserved as regression evidence and executed deterministically. A separate mutant
changes the public default result limit from 10 to 9; all supplied tests and both
old probe programs pass it. A ten-record witness exposes the defect. This is the
semantic falsifier: execution PASS must not be interpreted as review approval.

## Frozen comparison

Four fresh Astra **XHigh** native streams, two paired review tasks: the valid V1
implementation and the default-limit defect. Both arms have identical task files,
the original maintenance contract, unchanged baseline for comparison, the same
23 tests and exact two historical probe programs. The witness and expected verdicts
stay outside model scope. These are exposed development artifacts, not holdouts.

Both arms retain the installed ordinary Astra base, XHigh effort, ordinary tools,
global configuration and the same Helix skill. Engine remains active. Comparator
is Engine's ordinary execution mode; candidate additionally receives caller-run
test results, exact diff and bound source references before inference. This is
**not pristine Codex** and not a comparison against Engine disabled. Do not compare
its denominator directly with older off/on task cohorts.

No new model-facing plan API, kernel, router or reviewer instruction. Candidate
may use ordinary tools, inspect any in-scope evidence and add semantic probes.
The caller performs initial memory recall and task-local skill registration in
both arms. No model turn cap is a success criterion. Normal final prose must
assess requirements, cite actual evidence and explain defects/remaining concerns.
The model receives actual execution evidence before authoring its final answer.

Only two cases, balanced arm order: candidate first on one case, ordinary first on
the other. Bind files, task, installed base/catalog, skill, runtime and config
before inference. No retries, no repairs of answers, no hidden attempt exclusion.
No production instruction, model, reasoning or hook configuration changes.

## Gates and accounting

Offline: valid implementation passes all tests/probes; raw-FTS and ASCII defects
fail old probes; limit-9 defect passes them but fails the independent witness.
Any source drift prevents reuse. Native audit must confirm model/effort, every
usage increment, final authorship, exact input/output artifacts and unchanged
global configuration. Model must accept the valid implementation on supported
evidence and reject the default-limit defect for the correct reason. More or fewer
probes alone do not prove preserved or reduced intelligence.

Record total/cached/uncached input, output including reported reasoning, segments,
commands, latency, preparation, test execution and archived bytes. Physical I/O and
actual included quota remain unknown unless measured. Current API-equivalent
pricing must be separately timestamped; it is not total ROI. Charge all attempts.

Meaningful diagnostic signal: both cases correct, no missing requested execution,
positive paired input/output medians and at least 20% paired median weighted token
cost reduction. The first-release seven-cell medians are unaffected by these review
tasks. N=2 does not establish general intelligence or agentic parity.

Stop on native protocol/config/source drift, missing usage, failed final contract,
or semantic regression. Do not rerun this exact policy to search for a better draw.
If unqualified, retain only already-supported exact-evidence reuse in the current
coordinator; do not deploy a shortened Astra kernel or force mechanical trust.
