# Astra XHigh: resident evidence preserved the challenge, not the hoped-for cheap path

**OBSERVED — scoped safety PASS; economics unqualified.** Astra rejected the
query-specific defect despite 612 passing prepared comparisons, 23 passing
supplied tests and two passing historical probe programs. It independently tested
matching evidence, missing index entries and corrupted source objects. Its exact
model-written final reports nine failures and nine corresponding controls.

**DECISION — stop this candidate.** Complete evidence upfront did not eliminate
inspection and probe construction: four model segments and four shell commands
remain. No fresh paired control was authorized by this protocol, so there is no
measured saving, regression percentage, release median or model freeze. No further
call or self-deployment follows automatically from this safety pass.

## What was tested

The user authorized experiments after research and offline gates. The preceding
[semantic-emulation audit](../SEMANTIC_EMULATION_AUDIT_20260910.md) found no supported
way to switch hosted Astra into a free latent semantic emulator. Existing traces
also showed that apparently expensive new probes could catch defects the prepared
tests missed. The qualified [differential comparisons](../differential-obligations-v1/RESULT.md)
therefore retain an explicit distinction between finite agreement and semantic
adequacy.

This composition made exact task, reference, candidate, evidence-store code,
supplied test code, historical probes and comparison-executor code resident before
the first model segment. Caller memory recall, skill activation and actual test
execution were completed in advance. The model kept the original base, XHigh
effort, ordinary tools, independent-probe authority and normal prose final.

The exposed calibration candidate passes every prepared comparison but returns an
empty result for one legitimate query before searching or checking integrity.
The prompt contained its literal source; it did not name the mutant, reveal the
expected verdict or contain our independent witness. This is not a blind holdout.

Implementation/protocol freeze: `794d593`, branch `Helix-Output`.
Manifest: `24f2bea20586f35eceaa8bec712679d8c28fe7adce06981300987e177b85b292`.
The three new admission tests rejected stale preflight authorization, changed
source and duplicate/interrupted starts before any inference. Existing six
differential-boundary tests and public verification were previously completed;
they are not counted as new model evidence. The actual task directory passed
all pre-execution comparisons and regressions. Native preflight made zero model
turns; the experiment made exactly one user turn with no retry.

## Capability finding

The [unchanged final](artifacts/final-answer.md) rejects the early return because
it hides a matching record and skips detection of both a missing nonmatching index
row and a corrupted nonmatching source. Each occurs under default, `all` and `any`.
Queries with trailing whitespace have identical literal tokens and correctly
exercise the ordinary path.

We retained the exact model-generated [probe](artifacts/probe.py), then replayed
it on the observed defective source and the previously valid candidate. The
defective replay exactly reproduces nine failures and nine passing controls;
the valid replay produces zero failures and nine passing controls. Both probes
exit zero because they report observations, so the audit checks their actual
results rather than treating exit zero as semantic correctness. These are
deterministic cross-replays, not independent model replication.

All original task files, source/config bindings, native model/effort and final
authorship passed the [audit](AUDIT.json). No caller rewrote the answer. No
implementation fix was made to the review fixture or to production Engine.

## Full accounting limits

Caller preparation took 1.805 seconds: the comparison subset took 0.927 seconds,
the supplied regressions 0.566 seconds, and memory recall 0.154 seconds. These
are components of preparation, not additional additive totals. The prompt was
59,548 bytes plus a 395-byte registration prefix and separately attached/runtime
instructions. It retained eight task files verbatim and the actual comparison
executor. This is a measured input cost, not proof of minimum sufficient evidence.

The comparisons read 2,954,298 object bytes, hashed 2,994,748 bytes, wrote 39,590
object bytes and performed 22,596 object reads. They retained 730,461 raw outcome
bytes. Memory recall retained 62,544 raw bytes; records from other task scopes
were excluded from the model packet. Exact native capture retained 262,932 bytes.
These are different accounting surfaces and must not be summed into a physical-I/O
claim. Full physical I/O and hosted/internal compute remain unmeasured. The two
post-run witness replays took about 0.168 seconds in total.

The dated [official pricing snapshot](PRICING.json), fetched from the
[OpenAI pricing source](https://developers.openai.com/api/docs/pricing.md), gives
candidate API-equivalent scenarios of $0.541556 short context or $1.024537 long
context. These are not actual Codex billing, included-plan quota, or complete
research ROI. The HUD independently refreshes tariffs and expires stale values;
this historical snapshot does not change. Coordinator research, admission tests,
preflight, audit and failed prior experiments are additional costs. Their omission
from the native candidate row is not a claim they are free.

## What this changes

**STRENGTHENED:** keep semantic adequacy with Astra. Finite deterministic evidence
was useful but insufficient; the new witness established real additional facts.

**WEAKENED:** giving Astra all source and comparison machinery upfront will, by
itself, collapse discovery and semantic probing into a cheap final segment. This
exact exposed candidate retained four segments and a 34,001-token first charge.
It should not proceed to a costly pair on the assumption that resident text will
automatically prevent repeated work.

**CONDITIONAL:** reusing previously established semantic obligations remains valid
only within their checked authority/dependency boundary. A new query exception is
new unresolved behavior, not a deterministic continuation of a passing corpus.

**UNKNOWN:** the paired economic effect, representative capability parity and
the minimum safe semantic cost for hosted Astra. Earlier exposed runs are not
matched controls for this new defect and prompt; none is substituted here.

The next research step must target a measured responsibility rather than add
another broad packet. This trace identifies concrete costs in constructing a
probe and obtaining a usable diff, but it does not prove either can be removed
safely by a new abstraction. Any proposed typed operation must first survive
offline applicability, coverage, admission-tax and complete-cost checks. This
result authorizes no further model run under the one-shot protocol.
