# Frozen native benchmark sources

Original inspected source files and synthetic fixtures, including exposed answer keys after the runs. SOURCE_MANIFEST.json binds this publication snapshot; per-iteration manifests retain their original pre-run commitments and differing dependency coverage. This is not a one-command portable harness. The original layout was work/helix-frontier under a workspace, with preflight.py under work/astra-80 and a private recall.json. That memory file and native traces are deliberately not included. Reproduction requires an authorized native Codex client, the original CLI/runtime capabilities, and adaptation of workspace layout and memory-consultation receipt. Any adapted run is a new experiment, not a byte-identical replay. No raw private session history is published.
