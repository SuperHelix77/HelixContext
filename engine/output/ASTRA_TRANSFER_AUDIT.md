# Astra High: evidence before the first V3 transfer

Sol is frozen as a bounded research candidate. Its effect does not transfer by
assertion to Astra. The next experiment keeps the V3 mechanical boundary and
changes only the declared model within a fresh off/on comparison.

| Earlier development contrast | Native input saving | Native output saving | Observation |
|---|---:|---:|---|
| Exact query V2 | 25.67% | 38.63% | Commands fell from two to one; Astra still read exact source spans |
| Model-invoked renderer | -89.21% | -26.30% | Commands rose from two to four; Astra read renderer/helper implementation |
| Typed terminal V2 | 31.83% | 33.80% | Related to query fixture, not an independent third task |

The first two raw Astra traces were rehashed against their stored native status
receipts before this experiment. Query control used 44,405 input / 277 output;
candidate 33,006 / 170. Renderer control used 43,710 / 673; candidate 82,703 / 850.
The efficient ordinary renderer control is a warning against treating output
length as evidence of removable cognition. The new transfer targets the actual
extra helper-discovery loop, not shorter formatting alone.

V3 transfers native skill attachment, caller-owned exact completion, complete
small policy history, verified metadata and typed preflight presentation. High,
normal tools, raw source access and exact semantic/artifact checks are retained.
No Engine source code is placed in the candidate task directory. Tools remain
available for necessary semantic verification and recovery.

The fresh protocol freezes two calls, fixed off/on order, and prospective limits
of 200,000 native input / 6,000 output per call. The larger input ceiling is
specified before Astra executes because Sol's app-server control used 167,119;
it is not an amendment after observing Astra. Stop on failure or overrun, retain
all usage, and do not tune a prompt in response to its control. Astra must clear
80% separately on both axes; Sol's 75% concession is not silently generalized.

This is one reused development fixture family, not three representative tasks
or a long-horizon parity certificate. Query and typed-terminal reports use a
related log family; counting them as independent tasks would overstate coverage.
The requested representative matrix and native latent-future-relevance/recovery
gates remain open even if this transfer clears its numeric gate.

resolves to `/private/tmp`. Comparing unresolved path prefixes omitted in-repo
sources from the profile. Canonical containment now binds 16 verified source
